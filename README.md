# Project Overview:
This project involves the design and development of a website for Gauteng Higher Learning Institution, a fictional private higher education institution. The website aims to provide information about the institution, its courses, admission enquiries and contact details through five web pages: Home, About Us, Courses, Enquiries and Contact. The project will be developed using HTML and later enhanced with CSS to create a professional, user-friendly and responsive website.
# website Goals and Objectives
The primary goal of the website is to establish a professional online presence for Gauteng Higher Learning Institution and provide students, parents and other stakeholders with easy access to accurate and up-to-date information about the institution.

## Objectives
Provide detailed information about the institution, including its history, mission, vision and values.
Display the academic programmes offered together with their duration and entry requirements.
Allow prospective students to submit enquiries through an online enquiry form.
Provide clear contact information, including the institution's address, telephone number, email address and office hours.
Improve communication between the institution and prospective students by making information available online.
Create a user-friendly website with clear navigation so that visitors can easily find the information they need.
Lay the foundation for future enhancements, such as an online application system and student portal.
## Key Performance Indicators (KPIs)
Increase the number of website visitors.
